# Chrome Web Store Listing Copy — JSON Visualizer

**Name (<=75 chars):**
JSON Visualizer — Tables & UI for API Responses

**Short description (<=132 chars):**
Renders JSON API responses as tables, lists, badges and trees. Three views: Visual, Pretty (highlighted), Raw. Zero data collection.

**Full description:**
Tired of staring at walls of raw JSON? JSON Visualizer turns any JSON response in your browser into real UI elements.

• VISUAL VIEW — arrays of objects become sortable, searchable tables; flat objects become definition grids; scalars become color-coded type badges (strings, numbers, booleans, null); small flat objects like geo coordinates render as compact inline chips.
• PRETTY VIEW — syntax-highlighted tree with line numbers, indent guides, and collapsible nodes — like Pretty Print, but built in.
• RAW VIEW — the exact bytes from the server, untouched, for when you need ground truth.

Other features:
• Toolbar to switch views, search/filter table rows, expand/collapse everything
• Copy formatted JSON or download the original response
• Light & dark themes (follows your preference)
• 100% local processing — your data never leaves your browser. No analytics, no accounts, no network calls.

Perfect for developers debugging REST APIs, viewing GitHub/Firebase/Stripe responses, or exploring any JSON endpoint.
